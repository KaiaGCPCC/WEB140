Leveling-Up Web Design

Image editing can completely transform simple photos into eye-catching visuals for your website, and the use of icons in web design are a great way to communicate ideas, assist users with navigation, and personalize pages. This project explores four image editing techniques by modifying gaming imagery, describes how each effect can be used to enhance photographs, and demonstrates how the addition of icons can amplify web design and user experiences.

Leveling-Up Web Design with Imagery

Level 1: Image Editing

The following image gallery demonstrates four image editing techniques using Canva to enhance various gaming photos.

01. Retro Mode - Black & White

This Steam Deck image was modified using a classic black and white editing technique. Removing the color brings the device and its features to the forefront, putting more emphasis on the device's shape and highlighting its design, creating a classic, timeless image.

02. Nostalgic Neon — Saturation

This retro arcade image was enhanced by toggling the saturation settings. Increasing the saturation brings out the vibrant neon colors in the photo, creating a bright and exciting image that makes these gaming classics pop.

03. Shadow Strike — Contrast

This PC Gaming image was modified by increasing the contrast, an editing technique that emphasises shadows and lighting. This draws attention to the graphics on the screen, making them the focal point and creating a stronger visual impact.

04. 1-Player Color Quest — Monochromatic

This PlayStation controller photo was edited using a monochromatic color filter. Similar to the black and white edit, monochromatic editing utilizing a single color variation draws attention to the controller, but the purple hues create a unique, eye-catching visual without taking away from the remote's details and silhouette.

Leveling-Up Web Design with Icons

Level 2: Icon Study

The addition of icons to a webpage can enhance themes and create an interesting, charismatic visual experience for users. Using Font Awesome, several supporting icons were selected for this study, and customized with CSS to fit the overall theme of the webpage.

Theme Indicators

Theme related iconography, like this GamePad to indicate this page's gaming inspired theme, helps web designers immediately communicate the main theme/idea of the website.

Stylization

Choosing supporting nav button icons provides a creative way to customize webpage navigation and create visual interest for users.

Creative Usability

Using unique icons for contact and redirection tabs is a great way to transform simple communication features and personal/brand information to fit a webpage's theme, allowing designers to express creativity while also maintaining usability.
