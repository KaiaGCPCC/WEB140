Explaining Design Choices

My Color Analysis

Each color palette for this assignment was picked with the intention of creating dynamic, visually appealing web designs using harmonious color schemes. Below is a thorough analysis of each palette, and how I would use them in a website.

Palette 1

Harmony: Complementary

Why I selected these colors: These colors were chosen using Complementary harmony, where colors that are directly across/opposite from each other on the color wheel are paired together to create a balanced and unique palette. I picked this arrangement because I particularly loved the contrast between the moody blue-green hues and the rich browns. It also reminds me of mint chocolate chip ice cream!

Mood: I think this palette creates a calm, grounding mood. The combination of refreshing teal tones and earthy browns create a harmonious color scale for a pleasant, welcoming layout.

Website Usage: I would use the dark blue-green color (#248068) of this palette for headings and main sections, the warm reddish-brown (#802B11) for the navigation bar/section, and the cool mint color (#97D4C4) The soft white (#FFF5F2) would be the background color for main areas, and the rich espresso brown (#402118) would be the main text color.

Palette 2

Harmony: Analogous

Why I selected these colors: I picked these colors using Analogous harmony, which is where colors are adjacent to each other on the color wheel, creating a smooth transition between hues. This palette of warm colors immediately stood out to me, and I believe they create a visually appealing interface, while the transitional tones between the bold pink and vibrant yellow demonstrate tonal cohesion. The colors remind me of Starburst candy!

Mood: I would describe the mood of this palette as fun and vibrant! I think the blend of pink and orange/yellow hues create a warm and inviting visual experience.

Website Usage: For this palette, I would utilize the bold pink color (#FF1C36) for major sections and headings, the sunset-orange color (#FF3C1C) for navigation, and the marigold color (#FFB32B) primarily for buttons and as a contrasting support color throughout the site. The soft cream/peachy color (#FFE0C2) would be the background, and the tangerine orange (#FF641C) would be the primary text color.

Palette 3

Harmony: Triadic

Why I selected these colors: This palette demonstrates Triadic harmony, when colors are spaced around the color wheel in a triangular shape to create a vibrant and dynamic color scheme. I chose this arrangement of colors because I thought the warm reds, bright blues, and pastel yellow-green create an interesting, playful contrast. The primary blue and background color remind me of the character Mametchi from Tamagotchi!

Mood: I believe this palette channels a bold, energetic mood. The combination of saturated, high-contrast shades and deeper hues against a pale background creates a lively appearance while also keeping the colors balanced and harmonious.

Website Usage: I would apply the midnight blue color (#0E4175) primarily to main headings and containers, the bright reddish-orange color (#F54033) for interactive elements and navigation, and the vibrant azure color (#1A87F5) for buttons and small accents across the page. The pale yellow-green (#F0F5CA) would be the background supporting the bolder colors, and the brick-red (#A11208) would serve as the main text color.
